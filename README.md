A user can add products to the cart from the products page. Once a product is added, it should appear in the cart with its current price.

When the user removes a product from the cart, that product should be removed successfully. After removal, the price of the removed product should change on the products page.

If the user adds the same product to the cart again, it should be added with its newly updated price, while the prices of all other products should remain unchanged.
